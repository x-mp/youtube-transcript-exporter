# Privacy Policy

Effective date: May 18, 2026

YouTube Transcript Exporter is a Chrome extension that helps users export YouTube video transcripts and visible video metadata into a local text file.

This extension is an independent tool and is not affiliated with, endorsed by, or sponsored by YouTube or Google.

## Data Access

The extension can read content from YouTube pages where it is active, including:

- Video title
- Video URL and video ID
- Channel name and channel URL
- Visible video metadata such as views, dates, duration, category, tags, thumbnail URL, and chapters
- Video description
- Transcript/caption text and timestamps

## Data Use

The extension uses this information only to generate a text file requested by the user.

## Data Sharing

The extension does not send, sell, rent, share, or transfer user data to any external server or third party.

## Data Storage

The extension does not maintain a remote database and does not store user data outside the downloaded text file created by the user.

## Permissions

The extension uses the Chrome Downloads permission to save the generated transcript file locally.

## Limited Use Statement

The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

## Contact

For privacy questions, use the support contact listed on the Chrome Web Store item page.
